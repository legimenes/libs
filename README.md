# libs

A library of reusable components that accelerates application development while ensuring greater standardization and consistency across projects.

**Available libraries**

Name | Technology | Description
-|:-:|-
**Results** | .NET | A design pattern used to explicitly represent the result of an operation, avoiding the excessive use of exceptions for flow control. Instead of simply returning a value or throwing errors, the operation returns an object that indicates whether it was successful, contains the data produced, and, in case of failure, details about the error that occurred.
